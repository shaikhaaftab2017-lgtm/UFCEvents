# UFCEvents
A dynamic web application that fetches and displays upcoming UFC events using ESPN’s MMA API.

## Features
- Real-time event data fetching using Fetch API
- Async/Await handling
- Dynamic DOM rendering
- Safe API data access using optional chaining
- Responsive UI built with Bootstrap

## Tech Stack
- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap
- ESPN MMA API

## What I Learned
- Working with third-party APIs
- Handling nested API data
- Optional chaining for safer access
- Dynamic list rendering
